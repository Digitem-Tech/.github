# `.github` — configuración de Digitem-Tech

Este repositorio es el punto de configuración compartida de la organización de GitHub **Digitem-Tech**.

## Qué contiene

- [`profile/README.md`](profile/README.md): perfil público que GitHub muestra en la página principal de la organización.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): convenciones generales de colaboración y seguridad para los repositorios de Digitem.
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md): plantilla común para mantener las PR claras y revisables.

## Qué no debe contener

Este repositorio es **público**. No se guardan aquí:

- documentación interna de negocio;
- datos o nombres de clientes no publicados;
- credenciales, tokens o secretos;
- exportaciones de analítica, pedidos o información personal;
- documentación técnica privada de proyectos.

La documentación interna de Digitem vive en repositorios privados y cada cliente mantiene su información en su propio repositorio privado.

Para información pública sobre Digitem, consulta [digitemtech.com](https://digitemtech.com).
